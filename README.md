# Famicom-Discrete-Logic-Mappers-Cartridge-PCB

PCB for games that use discrete logic on the Famicom System

This board was ported over from Mousebitelabs NES board to a Famicom Board.

All I did was drag and drop the components, and do my best to make sure everything was connected.

This board has not been tested.
